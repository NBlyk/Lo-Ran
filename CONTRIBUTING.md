# Contributing

Run `matlab/tests/run_loran_tests.m` after changing MATLAB calculations.
Explain changes to sign, sampling grid, folded FFT bins, or frame averaging, and
compare against the bundled reference results. Preserve historical annotations
when reproducing the benchmark; new captures need independently validated windows.

Retain all upstream copyright and license notices. Identify the source and
license of any contributed dependency. Do not upload vendor firmware before its
redistribution terms have been resolved, and do not include private acquisition
paths, credentials, tool binaries, or unpublished personal information.

The repository URL and maintainer contact will be supplied by the authors before
publication. Use GitHub issues with MATLAB version, platform, a minimal example,
and a description of expected and observed behavior.
